# Avni

Notes for coding agents (and humans) working in this repository.

## Before you change anything

- Read [`CONTEXT.md`](CONTEXT.md) for the vocabulary — use its terms, not synonyms.
- Read the ADRs in [`docs/adr/`](docs/adr/) that touch the area you are in. If a
  change contradicts one, say so explicitly rather than silently overriding it.
  See [`docs/agents/domain.md`](docs/agents/domain.md).

## Issues

Issues and feature requests live on the project's GitHub issue tracker.

## Checks

`pnpm typecheck` and `pnpm test` must pass before a change is proposed.
